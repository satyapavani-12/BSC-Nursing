## In simple words

In real nursing, you do not use one skill at a time. You listen to the patient, speak to explain, read the chart and write notes — all together. This is integrated LSRW.

Combining the skills makes communication complete and safe.

## Integrated skills in practice

| Situation | Skills used |
|---|---|
| Patient education | Listen to fears, speak to teach, read the pamphlet, write the plan |
| Shift handover | Listen to the night nurse, speak to the day team, read the chart, write the report |
| Taking a history | Listen to the patient, speak your questions, read old notes, write the new entry |
| Giving medicines | Read the label, speak the instructions, listen to concerns, write what you gave |

## Patient education example

1. **Listen** — "What do you already know about your diabetes?"
2. **Speak** — explain diet and medicines in simple words.
3. **Read** — show and read the diet chart together.
4. **Write** — write down the medicine times for the patient to keep.

## Shift handover example

- Listen carefully to the outgoing nurse.
- Speak clearly about your patients.
- Read the charts and medication list.
- Write your own handover notes for the next shift.

## Where the nurse uses this

- **Patient education** — combine all four skills so the patient understands and remembers.
- **Shift handover** — listen, speak, read charts and write your report.
- **Admission** — listen to the story, speak your questions, read old records, write the new entry.
- **Discharge** — speak the advice, read the discharge card, write the plan for home.
- **Teamwork** — use all four skills with doctors, colleagues and the patient's family.

- LSRW skills combine in real nursing.
- Patient education: listen, speak, read, write.
- Handover: listen, speak, read charts, write report.
- Admission/discharge use all four skills.
- Combined skills = safe, complete care.
