## In simple terms

Emergency and disaster nursing involves responding to emergencies and disasters — from individual patient emergencies to mass casualty incidents. Nurses must know emergency codes, triage systems, and disaster response protocols.

## Common emergency codes

| Code | Meaning | Nurse’s action |
|---|---|---|
| Code Red | Fire | Rescue, Alarm, Confine, Extinguish (RACE) |
| Code Blue | Cardiac/respiratory arrest | Start CPR, call resuscitation team |
| Code Pink | Infant/child abduction | Secure exits, search, alert security |
| Code Silver | Violent person/weapon | Call security, do not confront alone |
| Code Black | Bomb threat | Follow evacuation instructions |
| Code Orange | External disaster | Prepare for mass casualties |
| Code Grey | Combative person | Call security, do not confront alone |

## Triage systems

| Triage category | Colour | Definition | Treatment priority |
|---|---|---|---|
| Immediate | Red | Life-threatening, treatable | Immediate |
| Delayed | Yellow | Serious but stable | Delayed |
| Minimal | Green | Minor injuries | Delayed/walking wounded |
| Expectant | Black | Dead or expectant | Palliative care only |

## Disaster management

- **Disaster phases** — mitigation, preparedness, response, recovery
- **Mass casualty incident (MCI)** — incident command system (ICS), triage, treatment, transport
- **Nurse’s role** — triage, treatment, transport, documentation, psychological support

## Where the nurse uses this

- **Emergency response** — know emergency codes; know your role in Code Blue, Code Red, Code Pink, Code Silver
- **Triage** — assess and categorize patients using triage categories; prioritize care based on acuity
- **Disaster response** — participate in disaster drills; know your role in the incident command system
- **Mass casualty** — triage, treat, transport; document patient information; coordinate with other agencies
- **Patient education** — teach disaster preparedness, emergency preparedness, first aid
