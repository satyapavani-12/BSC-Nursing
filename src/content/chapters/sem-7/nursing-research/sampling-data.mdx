## In simple words

The sample is the smaller group that is actually studied. Sampling must represent the population so that findings can be generalised.

## Population and sample

| Term | Meaning |
|---|---|
| Target population | Everyone the findings should apply to |
| Accessible population | Those actually reachable |
| Sample | The group selected for the study |
| Sampling frame | List used to select the sample |

## Sampling techniques

| Type | Technique | Feature |
|---|---|---|
| Probability | Simple random | Every member has equal chance |
| Probability | Stratified random | Random selection within groups |
| Probability | Systematic | Select from a numbered list at intervals |
| Probability | Cluster | Whole groups chosen |
| Non-probability | Convenience | Those who are easily available |
| Non-probability | Purposive | Selected deliberately because of knowledge |
| Non-probability | Snowball | Introduced by other participants |
| Non-probability | Quota | Fixed numbers from each group |

**Sample size** formulas use population, confidence level (usually 95%) and expected effect; larger samples reduce sampling error.

## Data collection tools

- **Questionnaire** — self-completed, can be open or closed
- **Interview schedule** — researcher asks and records
- **Observation checklist** — behaviour recorded
- **Rating scale** — graded response
- **Physiological measurement** — weight, pressure, blood or camera
- **Records** — existing notes and reports
- **Focus group and in-depth interviews** — for qualitative studies

## Validity and reliability

| Term | Meaning |
|---|---|
| Validity | Does the tool measure what it claims |
| Content validity | Experts confirm the items match the content |
| Face validity | The tool looks appropriate |
| Construct validity | Measures the intended concept |
| Criterion validity | Compares with an accepted measure |
| Reliability | Consistency and stability of a tool |
| Test-retest | Same result when repeated |
| Inter-rater | Two observers agree |
| Split-half | Two halves of the tool agree |

<Callout type="must" title="Pilot study first">
  A small **pilot study finds confusing questions, missing options and time problems** before the main data collection. A tool that has not been piloted can waste the whole study.
</Callout>

## 60-second revision

- Population, sample, frame; sample stands for the population.
- Probability: random, stratified, systematic, cluster.
- Non-probability: convenience, purposive, snowball, quota.
- Tools: questionnaire, interview, observation, records, measurement.
- Validity, reliability, pilot study.
