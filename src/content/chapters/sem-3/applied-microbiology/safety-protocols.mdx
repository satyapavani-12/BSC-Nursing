## In simple words

Hospitals use emergency codes to alert staff quickly and standardise responses to emergencies. Nurses must know the codes and their role in each.

Common codes: fire, cardiac arrest, infant abduction, violent person, bomb threat, evacuation, external disaster.

## Common emergency codes

| Code | Meaning | Nurse's action |
|---|---|---|
| Code Red | Fire | Rescue, Alarm, Confine, Extinguish (RACE) |
| Code Blue | Cardiac/respiratory arrest | Start CPR; call the resuscitation team |
| Code Pink | Infant/child abduction | Secure exits; search; alert security |
| Code Silver | Violent person/weapon | Call security; do not confront alone |
| Code Black | Bomb threat | Follow evacuation instructions |
| Code Orange | External disaster | Prepare for mass casualties |
| Code Gray | Combative person | Call security; de-escalate |

## Fire safety: RACE and PASS

- **RACE**: Rescue patients in danger, Activate alarm, Confine fire (close doors), Extinguish or Evacuate.
- **PASS**: Pull pin, Aim at base of fire, Squeeze handle, Sweep side to side.

## Where the nurse uses this

- **Know the codes** — memorise your hospital's code meanings and response.
- **Code Blue** — start CPR if trained; call the resuscitation team; bring the crash cart.
- **Fire** — use RACE and PASS; know nearest extinguisher and exit.
- **Code Pink** — secure exits; do not let anyone leave with a baby; alert security.
- **Violent person** — call security; keep distance; do not confront alone.

## 60-second revision

- Emergency codes = standardised alerts for emergencies.
- Code Red = fire; Code Blue = arrest; Code Pink = infant abduction; Code Silver = violent person.
- Fire: RACE (Rescue, Alarm, Confine, Extinguish); PASS (Pull, Aim, Squeeze, Sweep).
- Code Blue: CPR + call resuscitation team.
- Know your hospital's codes.
