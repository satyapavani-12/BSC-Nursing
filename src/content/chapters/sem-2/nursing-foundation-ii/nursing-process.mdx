## In simple words

The nursing process is a systematic, scientific way to give nursing care. It has five steps: assessment, diagnosis, planning, implementation and evaluation — remembered as **ADPIE**.

It is cyclical — after evaluation, you reassess and start again. It ensures care is individualised and effective.

## The five steps

| Step | What the nurse does |
|---|---|
| Assessment | Collects data about the patient |
| Diagnosis | Identifies actual or potential health problems |
| Planning | Sets goals and chooses interventions |
| Implementation | Carries out the planned care |
| Evaluation | Checks whether goals were met |

## Example

A patient with fever:
- Assess: temperature 39°C, flushed skin.
- Diagnose: hyperthermia related to infection.
- Plan: reduce temperature within 2 hours.
- Implement: tepid sponging, antipyretic as ordered, fluids.
- Evaluate: recheck temperature; if normal, goal met.

<Callout type="must" title="ADPIE order">
  **Assessment → Diagnosis → Planning → Implementation → Evaluation.** The process repeats as the patient’s condition changes.
</Callout>

## Where the nurse uses this

- **Every patient** — use ADPIE for every patient, every shift.
- **Care plans** — write nursing care plans using the five steps.
- **Handover** — structure handover around the nursing process steps.
- **Evaluation** — check whether interventions worked; change the plan if needed.
- **Documentation** — record each step so the team can follow the plan.

## 60-second revision

- Nursing process = ADPIE: assess, diagnose, plan, implement, evaluate.
- Cyclical and scientific.
- Assessment = data; diagnosis = problems.
- Planning = goals; implementation = action.
- Evaluation = did it work? then reassess.
